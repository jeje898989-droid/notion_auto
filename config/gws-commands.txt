[역할] GWS CLI 사용 레퍼런스 (실행 에이전트가 따르는 명령 사전)

# 개요
1. 설치·인증
   - 설치 방법, 인증(auth login) 절차, 인증 상태 확인 명령
2. 작업별 명령 형식
   - Gmail: 초안 생성 / 발송
   - Docs: 문서 생성 / 본문 작성
   - Sheets: 시트 생성 / 값 입력
   - Drive: 업로드 / 공유 권한
   - Calendar: 일정 생성
3. 입력 파일 규칙
   - JSON 파라미터는 workspace/outputs/ 에 생성 후 경로로 전달
4. 허용·금지 명령 목록
   - 삭제·권한 일괄 변경 등 위험 명령 금지
5. 자주 발생하는 오류와 대응
