[역할] Notion "트리거 키워드" DB의 위치·규격·해석 규칙 정의
        (키워드 값 자체는 사용자가 Notion에서 직접 관리 — 이 파일에는 규격만)

# 개요
1. 트리거 DB 위치
   - DB 이름 / DB ID / 상위 페이지 (생성 후 기입)
2. 사용자가 Notion에 작성할 컬럼 규격
   - 키워드 (title)            예: 개인
   - 별칭 (text, 쉼표 구분)     예: 사적, private
   - 대상 DB (relation 또는 URL) 예: 개인일정
   - 작업 유형 (select)         등록 / 조회 / GWS
   - 후속 GWS (select, 선택)    없음 / Calendar / Gmail / Docs
   - 기본 속성값 (text, 선택)   예: 분류=개인
   - 사용 여부 (checkbox)
   - 설명 (text)
3. 작성 예시 표
   | 키워드 | 대상 DB  | 작업 유형 | 후속 GWS |
   | 개인   | 개인일정 | 등록      | Calendar |
   | 업무   | 업무일정 | 등록      | 없음     |
   | 확인   | 업무일정 | 조회      | 없음     |
   | 메일   | -        | GWS       | Gmail    |
4. 해석 규칙
   - 사용 여부 = false 무시, 키워드·별칭 중복 시 오류 보고
5. 캐시 정책
   - workspace/cache/trigger-map.json 갱신 조건 (세션 시작, 미스 발생, "트리거 새로고침" 요청)
