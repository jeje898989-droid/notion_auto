# nt-study (한글 번역본)

> 규칙: **학습 관련** 할 일은 Notion Study DB에 저장한다.

## 대상 DB

| 항목 | 값 |
|---|---|
| DB | 학습 일정 (Study) |
| Database ID | `418ce7a3-ff80-81f9-b5ec-cdb4d238bb72` |
| Data source | `collection://418ce7a3-ff80-81b9-b2f2-000b301b899e` |

## 학습 항목 기준

- 학습 관련 할 일: 강의, 수업, 학습용 독서, 과제, 시험, 자격증, 어학, 코딩 연습.
- 학습 항목은 **모두** 여기에 저장한다 — 개인 일정에 `분류 = 공부`로 저장하지 않는다.
- 학습이 **아닌** 것: 학습 목표 없는 취미 (→ [nt-personal](_nt-personal.md)), 업무 (→ [nt-work](_nt-work.md)).

## 속성 매핑

| 속성 | 규칙 |
|---|---|
| 학습주제 (title) | 핵심 주제·작업, 예: `영어 단어 50개 암기` |
| 마감일 | 절대 마감 날짜, 시간이 있으면 datetime (없으면 질문) |
| 요약 (텍스트) | 학습 내용 요약 — 교재, 페이지, 링크 |

- 기존 컬럼 과목 / 상태 / 메모는 DB에 남아 있지만(이전 항목 보존용) 새 항목에는 **채우지 않는다**.

## 절차

1. 위 기준으로 학습 항목인지 분류한다. 개인이나 업무일 수도 있으면 → 사용자에게 질문.
2. `notion-db-register` → 사용자 승인 → `notion-writer`로 등록.
3. 승인 없이 절대 등록하지 않는다.
