# nt-personal (한글 번역본)

> 규칙: **개인** 할 일은 Notion Personal Tasks DB에 저장한다.

## 대상 DB

| 항목 | 값 |
|---|---|
| DB | 개인 일정 (Personal Tasks) |
| Database ID | `bdf037d2-af15-4e6a-8944-77524c2fd85e` |
| Data source | `collection://ac86ce0e-5079-4e11-a0c1-b3b8f74b85f8` |

## 개인 항목 기준

- 사생활 관련 할 일·약속: 친구/가족 만남, 취미, 운동, 볼일, 집안일, 건강, 쇼핑.
- 개인이 **아닌** 것: 직장·업무·고객 관련 (→ [nt-work](_nt-work.md)), 학습·공부 (→ [nt-study](_nt-study.md)).

## 속성 매핑

| 속성 | 규칙 |
|---|---|
| 일정 (title) | 핵심 행동, 예: `친구와 카페약속` |
| 날짜 | 절대 날짜, 시간이 있으면 datetime (**필수** — 없으면 질문) |
| 분류 | 약속 / 운동 / 취미 / 기타 (공부는 **사용하지 않음** — 학습은 Study DB로) |
| 상태 | 기본값 `예정` |
| 메모 | 장소, 참석자, 기타 세부 사항 |

## 절차

1. 위 기준으로 개인 항목인지 분류한다. 업무나 학습일 수도 있으면 → 사용자에게 질문.
2. `notion-db-register` → 사용자 승인 → `notion-writer`로 등록.
3. 승인 없이 절대 등록하지 않는다.
