# nt-work (한글 번역본)

> 규칙: **업무 관련** 할 일은 Notion Work DB에 저장한다.

| 항목 | 값 |
|---|---|
| DB | 업무 일정 (Work) |

| Data source | `collection://5cb7d5ec-8592-4927-b3cb-a55643cbf7da` |

## 업무 항목 기준

- 직장 관련 할 일: 보고서, 회의, 마감, 프로젝트, 고객, 동료, 출장, 업무 메일.
- 업무가 **아닌** 것: 사생활 (→ [nt-personal](_nt-personal.md)), 자기계발 학습 (→ [nt-study](_nt-study.md)). 업무와 관련 있어 보여도 마찬가지 (예: 자격증 공부 = 학습).

## 속성 매핑

| 속성 | 규칙 |
|---|---|
| 업무 (title) | 핵심 작업, 예: `주간 보고서 작성` |
| 마감일 | 절대 마감 날짜 (없으면 질문) |
| 상태 | 기본값 `시작 전` |
| 우선순위 | 높음 / 보통 / 낮음 — 기본값 `보통`, "급함/ASAP" → 높음 |
| 프로젝트 | 언급된 프로젝트 이름 |
| 메모 | 기타 세부 사항 |

## 절차

1. 위 기준으로 업무 항목인지 분류한다. 개인이나 학습일 수도 있으면 → 사용자에게 질문.
2. `notion-db-register` → 사용자 승인 → `notion-writer`로 등록.
3. 승인 없이 절대 등록하지 않는다.
