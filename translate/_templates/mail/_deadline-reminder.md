# 마감 알림 메일 템플릿 (한글 번역본)

> 역할: 마감 관련 메일 본문 템플릿

## 1. 변수 정의

| 변수 | 의미 |
|---|---|
| `{recipient}` | 수신자 이름 |
| `{task_list}` | 마감 작업 목록 |
| `{due_date}` | 마감일 |
| `{sender}` | 발신자 이름 |

## 2. 제목 형식

```
[마감 알림] {due_date} 마감 작업 안내
```

## 3. 본문 구조

```
{recipient}님, 안녕하세요.

{due_date}에 마감되는 작업은 다음과 같습니다:

{task_list}

진행 상황을 확인해 주시고, 조정이 필요한 부분이 있으면 알려 주세요.

감사합니다.
{sender} 드림
```

순서: 인사 → 마감 작업 목록 → 요청 사항 → 마무리.

## 4. 톤 옵션

- **내부용**: 간결하고 부드러운 존댓말.
- **외부용**: 격식체, 충분한 맥락과 인사말 포함.

## 5. 다른 메일 템플릿 추가 규칙

- `templates/mail/`에 `<목적>-<유형>.md` 형식의 kebab-case로 저장한다 (예: `meeting-invite.md`).
- 한글 번역본은 `translate/_templates/mail/_<파일명>.md`에 추가한다.
